# ⌚ Zenith Ultra Smartwatch — Technology Product Website

A high-performance promotional webpage designed for the **Zenith Ultra Smartwatch**, completed as part of the **Creative HTML & CSS Webpage Projects Activity (Group 2 - Topic #10: Technology Product Website)**.

---

## 🌟 Project Overview
- **Project Topic:** Group 2, Project #10: Technology Product Website
- **Theme:** Futuristic, sleek dark glassmorphism aesthetic with electric cyan and sapphire glowing accents.
- **Technologies Used:** Semantic HTML5, Custom Responsive CSS3 (Flexbox & CSS Grid), Vanilla JavaScript (ES6+), FontAwesome Icons, Google Fonts (`Inter` & `Space Grotesk`).

---

## ✨ Features & Sections Included

1. **Header & Navigation Bar:**
   - Sticky navbar with glassmorphic blur and glowing logo.
   - Smooth navigation links (`#hero`, `#features`, `#specs`, `#pricing`, `#reviews`, `#purchase`).
   - Responsive mobile slide-down drawer with hamburger toggle.
   - "Pre-Order Now" CTA button.

2. **Hero / Product Showcase Section:**
   - Bold futuristic headline with gradient text fill.
   - High-resolution smartwatch imagery with glowing radial ring and hover perspective effect.
   - Floating feature badges (Clinical ECG + SpO2 biosensors, Dual L1+L5 GPS).
   - Core metrics bar: 7 Days Battery, 2000 Nits Brightness, 100M Water Resistance, Grade 5 Titanium.

3. **Breakthrough Features Section:**
   - 6 detailed engineering highlight cards:
     - Aerospace Grade 5 Titanium (MIL-STD-810H)
     - 2000-Nit Always-On AMOLED Sapphire Display
     - BioCore Clinical Health Matrix (ECG, SpO2, Heart Rate)
     - 7-Day Ultra Endurance with Fast Wireless Qi Charging
     - 100m Ocean Water Resistance (EN13319 Scuba Standard)
     - Dual-Frequency Precision GPS with Offline Routing

4. **Technical Specifications Table:**
   - Clean, structured specification matrix detailing Display, Dimensions, Processor, Battery, Sensors, Connectivity, and Durability Ratings.

5. **Pricing & Editions Section:**
   - 3 Editions:
     - **Zenith Sport** ($299 USD)
     - **Zenith Ultra Pro (Titanium)** ($399 USD - Featured with ribbon)
     - **Zenith Celestial (Ceramic)** ($499 USD)
   - Interactive "Select Model" buttons that dynamically wire into the checkout customizer.

6. **Customer Reviews & Community Testimonials:**
   - 4.92 / 5 verified rating badge.
   - Testimonial cards from athletes, scuba instructors, and doctors with 5-star ratings.

7. **Interactive Purchase / Pre-Order Section:**
   - Live customizer with dynamic model switcher (Sport, Ultra Pro, Celestial).
   - Color swatch selector with instant visual indicator (Space Gray, Silver Frost, Ocean Navy, Rose Gold).
   - Real-time price calculation.
   - Customer shipping form with submission feedback and order confirmation.
   - Trust badges: 2-Year Official Warranty, 30-Day Free Returns, Worldwide Free Delivery.

8. **Footer & Trust Highlights:**
   - Multi-column footer with social links, warranty information, and newsletter subscription form.
